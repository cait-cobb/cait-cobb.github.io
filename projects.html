  • Predicting CYP2C9 drug metabolism with deep learning

    Machine Learning Algorithms, UC Berkeley, Spring 2025

    CYP2C9 metabolizes an estimated 15 to 20% of clinically used drugs. Our team built classifiers on 12,825 ChEMBL compounds, moving from a random forest to CNNs on SMILES images, transformer embeddings, and finally a dual-branch CNN that combines structure images with molecular descriptors. I also built a variational autoencoder for generating new molecules and diagnosed why it collapsed.

    95% validation accuracy, up from 72% for the random forest baseline.

  • GPU neural network training and profiling

    High Performance Computing, UC Berkeley, Spring 2026

    Ported a neural network's training loop from CPU to GPU, keeping training data on the device so almost nothing crossed the bus each epoch. Profiling on NERSC's Perlmutter showed the small model was limited by kernel launch overhead, so I scaled up to a three-body potential energy surface model.

    About 9 times faster than the CPU version, and GPU utilization rose from 16% to 93% on the larger model.

    • CUDA
    • PyCUDA
    • Nsight
    • Perlmutter

  • Parallel molecular dynamics with MPI

    High Performance Computing, UC Berkeley, Spring 2026

    Parallelized a Lennard-Jones molecular dynamics code so no single process ever holds all the particle data, and halved force calculations using Newton's third law. Strong-scaling, communication, and load-balance measurements showed that waiting between processes, not message overhead, was the real bottleneck.

    25.6 times faster on 64 cores than on one.

    • C++
    • MPI
    • Perlmutter

  • Vibrational modes from a quantum chemistry code

    Numerical Algorithms for Computational Quantum Chemistry, UC Berkeley, Fall 2025

    Extended a semi-empirical (CNDO/2) quantum chemistry code to calculate how molecules vibrate, using finite-difference Hessians, and generated animations of each vibration for molecular visualization software.

    Close agreement with NIST experimental data for hydrogen stretching modes, with larger errors for bending modes, a known limit of the method.

    • C++
    • Numerical methods
    • Avogadro

  • Detecting malaria-infected cells with an autoencoder

    Machine Learning Algorithms, UC Berkeley, Spring 2025

    Trained a convolutional autoencoder only on images of healthy cells, then flagged infected cells by how poorly the model could reconstruct them. Reviewing misclassified cells showed that unusually shaped healthy cells were the main source of errors.
